# HoldF5

HoldF5 is an MCTiers-approved freelook and perspective alternative for Fabric. Hold a key to temporarily switch to third-person view, then release it to return to first person.

## Features

- Smooth, configurable camera transitions
- Configurable third-person front or back perspective
- Optional motion blur during transitions on supported Minecraft versions
- Mod Menu configuration support

## Compatibility

- Minecraft 1.21–1.21.11
- Fabric Loader and Fabric API
- Java 21

Install the released `HoldF5` JAR in your instance's `mods` folder. Cloth Config is bundled with the mod; Mod Menu is optional.
